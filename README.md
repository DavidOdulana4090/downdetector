# Downdetector

Downdetector is a utility tool aimed at providing the functionality to verify if a specific site or service is currently down. This assists users in confirming potential outages with ease and reliability.

## Features
- URL validation with an active internet connection.
- Easy-to-use functionality for developers and other users.
- JDBC Driver for MySQL and PostgreSQL for database-driven analysis.

## Getting Started
To utilize this application effectively:
- **Languages:** Java
- Requirements:
  - JDBC Drivers for MySQL or PostgreSQL.
  - Internet connection for live URL validation.
